### Stream Deck plugin for X-Plane 12

Native plugin for **macOS** and **Windows**. Controls X-Plane 12 through its Web API: any DataRef or command on a button, live values and state-based images.

### What's New in v1.7.3

  - **Optional condition for DataRef Toggle and DataRef Switch** — a press is only executed if another DataRef meets a comparison, for example a switch that can only be turned on while the main switch is in position 2. This allows cockpit interlocks. The condition can apply to both directions or just one. If it is not met, the button shows the alert, or ignores the press silently with **Hide Blocked Alert**. Existing profiles are not affected.
  - **New EC135 profile** — added to the included helicopter profiles. Requires v1.7.3 or later.
