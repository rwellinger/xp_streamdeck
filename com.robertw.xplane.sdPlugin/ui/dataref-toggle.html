Flip the ON / OFF look (handle position + lit track) for DataRefs wired the opposite way. Does not change what is written / read. Momentary: write Value ON on press, Value OFF on release (e.g. test/reset button). Trigger Mode / Strict / Command paths are ignored. Treat only value === Value ON as ON (everything else is OFF) Orientation, Color and Static Label are rendered by the plugin into the button tile — no need to upload your own images. Important: if you DO assign custom State images (OFF / ON), they take precedence and will hide the generated tile (incl. the label). Reset the State images to default to get the generated look back.
Condition (optional)
Don't show the alert when the condition is not met — just ignore the press. Errors (e.g. DataRef not found) still show it. The press is only executed if the condition is met, otherwise the button shows the alert. Leave DataRef empty to disable.
